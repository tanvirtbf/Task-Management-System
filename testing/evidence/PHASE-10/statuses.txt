=== 2. CREATE — validation ===
  {"name":"TEST-s1","status_group":"active","color":"#1111   (valid)                                -> 201
  {"name":"TEST-s2","status_group":"todo","color":"#111111   ('todo' — is that a real group?)       -> 422 validation.failed
  {"name":"TEST-s3","status_group":"in_progress","color":"   ('in_progress')                        -> 422 validation.failed
  {"name":"TEST-s4","status_group":"bogus","color":"#11111   (unknown group)                        -> 422 validation.failed
  {"name":"TEST-s5","color":"#111111"}                       (no group)                             -> 422 validation.failed
  {"name":"","status_group":"active","color":"#111111"}      (empty name)                           -> 422 validation.failed
  {"name":"To Do","status_group":"not_started","color":"#1   (DUPLICATE of a default name)          -> 409 status.duplicate
  {"name":"TEST-s6","status_group":"active","color":"red"}   (non-hex colour)                       -> 422 validation.failed
  {"name":"TEST-s7","status_group":"not_started","color":"   (a 2nd not_started)                    -> 201

=== 4. LAST-IN-GROUP + IN-USE delete guards ===
  groups: not_started=2 active=2 done=2 closed=1
  delete a NON-last 'not_started' (2 in group) -> 204
  delete a NON-last 'active' (2 in group) -> 204
  delete a NON-last 'done' (2 in group) -> 204
  delete the LAST 'not_started'        -> 422 status.last_in_group
  the new task landed on status: To Do
  delete a status IN USE by a task     -> 409 status.in_use

=== 5. REORDER edge cases ===
  current order: To Do > In Progress > Done > Closed
  full set, reversed                         -> 422 validation.failed      order: To Do > In Progress > Done > Closed
  PARTIAL set (2 of 4)                       -> 422 validation.failed      order: To Do > In Progress > Done > Closed
  DUPLICATE id in the payload                -> 422 validation.failed      order: To Do > In Progress > Done > Closed
  a FOREIGN/unknown id appended              -> 422 validation.failed      order: To Do > In Progress > Done > Closed
  a status id from ANOTHER list              -> 422 validation.failed      order: To Do > In Progress > Done > Closed
  empty array                                -> 422 validation.failed      order: To Do > In Progress > Done > Closed
  no status_ids at all                       -> 422 validation.failed      order: To Do > In Progress > Done > Closed
